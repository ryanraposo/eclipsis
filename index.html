Backend architecture

Floating UI, push to talk, microphone capture, response audio playback, and text transcript.

Token Broker

Express server on EC2 or Azure VM keeps the OpenAI API key private and mints ephemeral client secrets.

OpenAI

Realtime API

WebRTC session to `gpt-realtime-1.5` for low-latency audio input and audio output.

How It Works

  1. Voice is captured in the App Clip.
  2. The client asks the Ubuntu server for an ephemeral OpenAI Realtime secret.
  3. The client opens a WebRTC session directly to OpenAI Realtime.
  4. The model streams speech and transcript events back to the floating window.
